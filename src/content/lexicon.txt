# Lemonade lexicon: every word and phrase the readings use, shared by all texts.
#
# Format
#   term                      a word or a phrase, lowercase, at the start of the line
#     gloss: ...              the main meaning (sense "default")
#     pos: ...                part of speech: noun, verb, adjective, adverb, pronoun,
#                             article, determiner, preposition, conjunction, number,
#                             name, or phrase (for any multi-word term)
#     lemma: ...              dictionary form, if different
#     note: ...               short grammar or usage note
#     name: yes               proper noun: never highlighted or tracked
#     words: a, b, c:sense    phrases only: which sense each word has inside the phrase
#     sense ID: gloss         another meaning; use it in a text as [term:ID]
#       lemma: / note: / pos: indented under a sense, they belong to that sense
#
# In a story, [le gusta] marks a phrase and [mañana:morning] picks a sense.
# Lines starting with # are comments.

  note: Literally "it pleases me".
  words: me, gusta
